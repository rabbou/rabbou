**Ruben Abbou**

Data scientist. I build deep learning models that detect disease early from the ECG. Cardiac amyloidosis at Anumana, with Pfizer, contributing to the model the FDA designated a Breakthrough Device; then at Idoven, leading the ATTR model published in Heart Rhythm in 2026 (20,754 ECGs from 2,901 patients), with its CE technical documentation.

In [ecg-conformal-shift](https://github.com/rabbou/ecg-conformal-shift), a study of whether an ECG model's promised reliability holds from one site to the next, on 45,923 tracings from three public datasets. In [ecg-data-chain](https://github.com/rabbou/ecg-data-chain), twelve public ECG datasets in one database where every tracing joins back to its source file.

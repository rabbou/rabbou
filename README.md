**Ruben Abbou**

Data scientist. I build deep learning models that detect disease early from the ECG. Cardiac amyloidosis at Anumana, with Pfizer, contributing to the model the FDA designated a Breakthrough Device; then at Idoven, leading the ATTR model published in Heart Rhythm in 2026 (20,754 ECGs from 2,901 patients), with its CE technical documentation.

In [ecg-ai-portability](https://github.com/rabbou/ecg-ai-portability), a study of whether an ECG model's positive predictive value can be predicted from one site to the next, over 174 transfers across six public corpora. In ecg-data-chain, fifteen public ECG distributions (459,113 tracings) in one database where every tracing joins back to its source file.
